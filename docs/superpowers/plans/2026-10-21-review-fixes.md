**Goal:** Remove every data-correctness defect, race and audit gap from the review, then the performance and UX defects, with a verified backup first and a test pinning each behaviour change.

Database changes ship as `supabase/v4.sql` (idempotent, applied by the user in the SQL editor), mirrored into `supabase/schema.sql` and a new `supabase/migrations/20261021120000_v4.sql` so a fresh install and the local stack match production.

**Tech Stack:** Next.js 16.2.9 App Router, React 19, TypeScript, Supabase (PostgREST, Postgres, Storage), zod 4, vitest 4, Tailwind v4, Recharts 3.
